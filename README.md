## 🏛️ AI酒馆

### 核心定位
**"不只是聊天，而是真正的情感服务"**

一个基于PromptX记忆技术的多模式情感AI平台，根据用户的不同情感需求智能切换专业化服务模式。

### 三大服务模式

#### 1️⃣ 表达模式 - "我想说话"
- 🗣️ 自由表达的安全空间
- 🧠 智能内容分类（情感倾诉vs目标记录）
- 💾 高质量记忆存储

#### 2️⃣ 安慰模式 - "我需要安慰"  
- 🤗 温暖的情感支持
- 🎵 实用减压工具
- 💖 个性化关怀

#### 3️⃣ 思考模式 - "我想思考" ⭐ 
- 🤔 深度反思引导（苏格拉底式提问）
- 💡 创意思维激发
- 🔍 行为模式识别

### 核心优势

**记忆技术突破**
- 不只存储"说了什么"，更分析"为什么这样想"
- 使用时间越长，理解越深，价值指数级增长
- 主动提供深度洞察，而非被动回答

## 🍳 美食搭子

### 核心定位
**"不要更聪明的AI，要更懂你的AI"**

基于PromptX记忆功能的智能饮食助手，解决用户"选择困难症+懒"的核心痛点。

### 记忆系统设计

#### 📋 个人饮食档案
- 🚫 过敏信息 - 永久避免过敏食材
- 💪 健康目标 - 减肥/增肌/养胃等长期目标跟踪
- 🙏 饮食禁忌 - 宗教、文化、个人偏好记录

#### 🏠 家庭食材库
- 📦 常备食材管理
- 🥬 时令食材追踪
- ⏰ 智能过期提醒

#### 👅 口味学习进化
- 📝 反馈学习（记住"太淡/太咸"的偏好）
- 🌶️ 偏好识别（重口味/清淡/特定菜系）
- 😌 情境适应（压力大时重口味，身体不适时清淡）

### 核心体验流程

```
用户：家里有鸡蛋、西红柿、面条
↓
AI推荐：西红柿鸡蛋面 + 个性化制作指导
↓  
🔹 你的偏好：你喜欢酸甜口，建议多炒汁水更浓郁
🔹 健康目标：在减肥期，建议少放油，约400卡
🔹 制作能力：适合新手，15分钟完成
```
