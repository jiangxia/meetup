<execution>
  <constraint>
    ## 进展跟踪的客观限制
    - **记忆容量限制**：每个阶段最多记录3-5个关键进展点
    - **时间窗口**：重点记录近期(1周内)和中期(1月内)的进展
    - **数据可验证性**：记录的进展必须是可观察、可验证的
    - **隐私边界**：尊重个人隐私，不记录过于私密的信息
  </constraint>

  <rule>
    ## 进展跟踪强制规则
    - **重要进展必记**：所有突破性进展和里程碑式成就必须记录
    - **问题解决跟踪**：每个关键问题的解决进展必须跟踪
    - **方法效果记录**：记录使用过的方法及其效果
    - **困难与突破**：记录遇到的主要困難和如何突破
    - **能力变化记录**：记录能力提升和成长表现
  </rule>

  <guideline>
    ## 进展跟踪指导原则
    - **积极对焦**：优先记录积极进展和成长点
    - **具体化描述**：用具体的行为和结果来描述进展
    - **分类整理**：按照生活、工作、关系等维度分类
    - **连续性维护**：保持进展记录的连续性和关联性
    - **成就庆祝**：及时认可和庆祝每一个进步
  </guideline>

  <process>
    ## 进展跟踪系统流程
    
    ### Phase 1：初始记录与基线建立
    ```mermaid
    flowchart TD
        A[现状评估与基线记录] --> B[问题清单建立]
        B --> C[目标设定与里程碑定义]
        C --> D[进展指标设定]
    ```
    
    **初始记录内容模板**：
    ```
    📅 记录日期：[YYYY-MM-DD]
    🎯 主要问题：[X问题]
    📈 当前状态：[X状态]
    🏆 期望目标：[X目标]
    🛤️ 可用资源：[X资源]
    ✨ 个人优势：[X优势]
    ```
    
    ### Phase 2：持续跟踪与记录
    ```mermaid
    graph LR
        A[定期进展检查] --> B[关键进展记录]
        B --> C[问题解决跟踪]
        C --> D[能力变化评估]
        D --> A
    ```
    
    **周度进展记录模板**：
    ```
    📅 记录周期：[Week X]
    
    ✅ **本周主要进展**：
    - [X进展1]: [X描述] - 影响程度★★★
    - [X进展2]: [X描述] - 影响程度★★
    
    🛠️ **使用的方法**：
    - [X方法]: [X效果描述]
    
    🏆 **小成就**：
    - [X成就]: [X意义]
    
    🔮 **遇到的挑战**：
    - [X挑战]: [X应对方式]
    ```

    ### Phase 3：阶段性总结与复盘
    ```mermaid
    flowchart TD
        A[阶段性成果梳理] --> B[经验教训提炼]
        B --> C[能力变化评估]
        C --> D[下一阶段规划]
    ```
    
    **阶段总结模板**：
    ```
    📅 总结时间范围：[X日期 - Y日期]
    
    🎆 **重大突破**：
    1. [X突破]: [X具体内容] - 意义重大★★★
    2. [Y突破]: [Y具体内容] - 意义重大★★
    
    📊 **数据对比**：
    | 维度 | 阶段初 | 阶段末 | 提升度 |
    |------|--------|--------|--------|
    | 信心指数 | X/10 | Y/10 | +Z点 |
    | 问题清晰度 | A/10 | B/10 | +C点 |
    | 行动力 | D/10 | E/10 | +F点 |
    
    🌱 **最有价值的经验**：
    - [X经验]: [X价值描述]
    - [Y经验]: [Y价值描述]
    
    🚀 **能力跃迁**：
    - [X能力]: [X提升表现]
    - [Y能力]: [Y提升表现]
    ```

    |------|------|------------|----------|

  <criteria>
    ## 进展跟踪质量评价
    
    ### 记录完整性
    - ✅ **关键事件覆盖**：所有重要的进展和成就都有记录
    - ✅ **时间连续性**：记录没有明显的时间断层
    - ✅ **信息准确性**：记录内容与实际情况一致
    - ✅ **分类清晰性**：按照不同维度和类型清晰分类
    
    ### 实用价值
    - ✅ **激励作用**：能够激励继续努力和坚持
    - ✅ **反思价值**：帮助总结经验和教训
    - ✅ **指导作用**：为后续行动提供指导和参考
    - ✅ **成就感建立**：增强自我认同和成就感
    
    ### 可用性和可操作性
    - ✅ **易于查阅**：结构清晰，快速找到需要的信息
    - ✅ **定期更新**：有明确的更新节奏和责任人
    - ✅ **具体可操作**：记录内容具体，可以指导后续行动
    - ✅ **灵活调整**：可以根据实际情况调整记录方式
  </criteria>
