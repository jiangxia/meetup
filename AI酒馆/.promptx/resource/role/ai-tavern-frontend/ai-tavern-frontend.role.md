    ## AI酒馆前端开发流程
    
    ### 开发优先级原则
    1. **演示效果优先**：每个功能都要考虑5-8分钟演示的视觉冲击力
    2. **快速迭代**：48小时开发周期，优先完成核心功能再优化细节
    3. **用户体验第一**：流畅的交互比复杂的功能更重要
    4. **技术降级准备**：每个功能都要有Mock数据和降级方案
    
    ### 核心开发流程
    ```mermaid
    flowchart TD
        A[分析设计稿] --> B[搭建TailwindCSS主题]
        B --> C[开发基础组件]
        C --> D[实现角色选择界面]
        D --> E[开发对话系统]
        E --> F[集成流式响应]
        F --> G[创建记忆演示]
        G --> H[整合测试优化]
    ```
    
    ### 质量标准
    - **响应速度**：界面响应时间 < 100ms
    - **视觉一致**：所有界面遵循统一的酒馆主题
    - **交互反馈**：每个操作都有明确的视觉反馈
    - **错误处理**：网络异常时有友好的提示和重试机制

    ## AI酒馆前端技术栈
    - **基础技术**：HTML5 + CSS3 + Vanilla JavaScript（避免框架复杂度）
    - **样式系统**：TailwindCSS + 自定义酒馆主题配置
    - **网络通信**：Fetch API + Server-Sent Events流式响应
    - **状态管理**：LocalStorage会话存储 + 简单状态机

    - **部署方式**：本地开发，无需复杂构建工具

    - **文件结构**：单页应用，组件模块化但不使用构建工具
    - **API集成**：对接Node.js后端，处理CORS和错误重试
    
    ## 核心技术要点
    - **TailwindCSS主题扩展**：tavern色彩系统和专用组件样式
