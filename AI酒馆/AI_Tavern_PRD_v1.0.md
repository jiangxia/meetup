# AI 酒馆 — 产品需求文档 (PRD v1.0)

## 1. 产品概述

AI 酒馆是一个基于 PromptX 协议的多 Agent 系统，核心演示目标是：体现 PromptX 的记忆功能和 Agent 概念。用户进入酒馆后，可以与不同人格的"调酒师 / 客人"交互，AI 会记住用户的情绪和偏好，在下一次对话中体现出来。

**核心价值**：让用户直观感受到 PromptX 带来的 情绪价值 + 记忆能力 + Agent 行为。

## 2. 用户目标

- **孤独的用户**：获得陪伴和倾听。
- **压力大的用户**：获得安慰和轻量化的缓解建议。
- **无聊的用户**：被引导进入轻松话题和互动氛围。
- **回访用户**：体验到 AI 记住了自己过去的情绪与偏好。

## 3. 使用场景

1. **初见**：用户进入酒馆，选择一个调酒师角色，对话时表达情绪（如"今天很累"），AI 共情回应，并保存记忆：user.feeling=疲惫。

2. **回访**：再次进入时，AI 主动提及过去的记忆（如"上次你说很累，今天好些了吗？"）。

3. **角色推荐**：在对话中基于用户状态和需求 → 系统生成"今夜角色推荐单"，推荐合适的PromptX专业角色。

4. **导出**：用户导出 PDF/卡片，展示推荐角色+使用建议。

## 4. 功能需求分析

### 4.1 核心功能需求清单

基于场景分析，确定以下核心功能需求：

**核心功能需求（3个）**：
1. **基础对话系统** - 接收用户输入，生成AI回应
2. **角色风格控制** - 不同调酒师角色的差异化回应（依赖PromptX角色系统）
3. **PromptX角色推荐** - 基于对话内容智能推荐专业角色

**界面功能需求（3个）**：
1. **角色选择界面** - 用户选择调酒师类型（温柔型/理性型）
2. **对话界面** - 基础聊天UI，支持文本输入输出
3. **推荐展示界面** - 显示PromptX角色推荐内容，支持导出

**需求简化说明**：
- ❌ **独立情绪识别**：由PromptX角色系统内置处理，无需单独实现
- ✅ **记忆功能**：通过集成PromptX记忆API实现，作为核心演示功能
- ✅ **角色推荐**：从传统"酒单"改为PromptX角色推荐，提供真实价值

### 4.2 用户交互流程设计

```
用户进入 → 选择调酒师角色 → 开始对话 → 表达情绪/需求 
    ↓
AI理解并回应 → 保存记忆 → 继续对话 → 触发角色推荐
    ↓
展示推荐角色 → 用户查看 → 导出推荐单 → 结束会话
```

| 功能模块 | 描述 | 需求细项 | 优先级 | MVP |
|---------|------|----------|--------|-----|

## 6. 非功能性需求

- **性能**：首次回复 < 2s；导出文件 < 5s。
- **稳定性**：记忆写入成功率 > 95%。
- **演示性**：5–8 分钟内可完整展示：角色选择 → 对话 → 记忆保存 → 回访 → 角色推荐产出。

## 7. 黑客松 MVP 范围

- ✓ Persona 选择（温柔型 / 理性型）。
- ✓ 对话（情绪识别 + 差异化回应）。
- ✓ 记忆（PromptX 记忆功能的核心演示：保存一次情绪，下次提及）。
- ✓ 今夜角色推荐单（基于对话内容推荐PromptX角色 + 导出）。

## 8. 后续迭代方向

- 更多角色（如"开朗气氛组"、"冷静导师"）。
- 多 Agent 协作（角色之间对话，制造群聊氛围）。
- 情绪日志：生成用户"情绪曲线"。
- 小任务引导：基于情绪推荐轻量行动（如"去散步"）。
- 个性化场景：用户选择酒馆氛围（安静爵士吧 / 热闹小酒馆）。

## 9. 风险与边界

- **技术风险**：情绪识别不准时需兜底。
- **伦理风险**：避免复刻真实亲友 → 强调虚拟陪伴定位。
- **演示风险**：LLM 延迟 → 需准备兜底模板内容。
- **角色推荐风险**：PromptX角色库连接失败 → 需要离线角色备份。
