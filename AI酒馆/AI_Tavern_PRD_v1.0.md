# AI 酒馆 — 产品需求文档 (PRD v1.0)

## 1. 产品概述

AI 酒馆是一个基于 PromptX 协议的多 Agent 系统，核心演示目标是：体现 PromptX 的记忆功能和 Agent 概念。用户进入酒馆后，可以与不同人格的"调酒师 / 客人"交互，AI 会记住用户的情绪和偏好，在下一次对话中体现出来。

**核心价值**：让用户直观感受到 PromptX 带来的 情绪价值 + 记忆能力 + Agent 行为。

## 2. 用户目标

- **孤独的用户**：获得陪伴和倾听。
- **压力大的用户**：获得安慰和轻量化的缓解建议。
- **无聊的用户**：被引导进入轻松话题和互动氛围。
- **回访用户**：体验到 AI 记住了自己过去的情绪与偏好。

## 3. 使用场景

1. **初见**：用户进入酒馆，选择一个调酒师角色，对话时表达情绪（如"今天很累"），AI 共情回应，并保存记忆：user.feeling=疲惫。

2. **回访**：再次进入时，AI 主动提及过去的记忆（如"上次你说很累，今天好些了吗？"）。

3. **持续对话**：用户可以继续与选择的AI角色进行深度对话，体验记忆功能的连续性。

## 4. 功能需求分析

### 4.1 核心功能需求清单

基于场景分析，确定以下核心功能需求：

**核心功能需求（2个）**：
1. **基础对话系统** - 接收用户输入，生成AI回应
2. **角色风格控制** - 不同调酒师角色的差异化回应（依赖PromptX角色系统）

**界面功能需求（2个）**：
1. **角色选择界面** - 用户选择调酒师类型（温柔型/理性型）
2. **对话界面** - 基础聊天UI，支持文本输入输出

**需求简化说明**：
- ❌ **独立情绪识别**：由PromptX角色系统内置处理，无需单独实现
- ✅ **记忆功能**：通过集成PromptX记忆API实现，作为核心演示功能
- ✅ **专注核心**：专注于多角色对话和记忆演示，避免功能复杂化

### 4.2 用户交互流程设计

```
用户进入 → 选择调酒师角色 → 开始对话 → 表达情绪/需求 
    ↓
AI理解并回应 → 保存记忆 → 继续深度对话 → 体验记忆连续性
    ↓
用户可随时切换角色 → 体验不同风格回应 → 结束会话
```

## 5. 核心功能明细

| 功能模块 | 描述 | 需求细项 | 优先级 | MVP |
|---------|------|----------|--------|-----|
| 角色系统（PromptX） | 用 PromptX 定义至少两个 Agent（温柔型/理性型） | 1. 预设角色配置<br>2. 用户可选择/切换角色<br>3. 每个角色包含 Persona/Emotion strategy/Memory policy/Boundaries<br>4. 支持加载新的角色配置 | 必须 | ✔ |
| 对话与情绪识别 | 识别用户情绪并给出差异化回应 | 1. 输入自然语言<br>2. 输出情绪标签（如：低落/开心/焦虑）<br>3. 根据角色风格回应<br>4. 保持自然语气 | 必须 | ✔ |
| 记忆机制（PromptX 重点） | 保存并应用用户的情绪和偏好，演示 PromptX 的记忆功能 | 1. 每轮输出 memory JSON（0-3 条）<br>2. 包含 subject/predicate/object/confidence/source_turn<br>3. 下次对话自动调用记忆<br>4. 用户可查看/删除记忆 | 核心 | ✔ |

| 伦理与边界 | 系统安全提示与边界开关 | 1. 默认关闭高风险功能<br>2. 提示虚拟陪伴用途<br>3. 提供开关机制 | 必须 | ✔ |



## 6. 非功能性需求

- **性能**：首次回复 < 2s；导出文件 < 5s。
- **稳定性**：记忆写入成功率 > 95%。
- **演示性**：5–8 分钟内可完整展示：角色选择 → 对话 → 记忆保存 → 回访 → 角色切换体验。

## 7. 黑客松 MVP 范围

- ✓ Persona 选择（温柔型 / 理性型）。
- ✓ 对话（情绪识别 + 差异化回应）。
- ✓ 记忆（PromptX 记忆功能的核心演示：保存一次情绪，下次提及）。
- ✓ 角色切换体验（用户可在对话中切换不同AI角色，体验差异化回应）。

## 8. 后续迭代方向

- 更多角色（如"开朗气氛组"、"冷静导师"）。
- 多 Agent 协作（角色之间对话，制造群聊氛围）。
- 情绪日志：生成用户"情绪曲线"。
- 小任务引导：基于情绪推荐轻量行动（如"去散步"）。
- 个性化场景：用户选择酒馆氛围（安静爵士吧 / 热闹小酒馆）。

## 9. 风险与边界

- **技术风险**：情绪识别不准时需兜底。
- **伦理风险**：避免复刻真实亲友 → 强调虚拟陪伴定位。
- **演示风险**：LLM 延迟 → 需准备兜底模板内容。
