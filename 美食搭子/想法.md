# AI美食专家 - 基于PromptX记忆功能的智能饮食助手

**核心Slogan**: "不要更聪明的AI，要更懂你的AI"

## 1. 项目定位

**黑客松活动**: 字节跳动黑客松，3小时开发时间
**双重目标**: 获奖 + 宣传PromptX
**核心需求**: 解决用户"晚餐选择困难症+懒"的问题
**项目名称**：美食搭子

### 价值主张
- **用户价值**: 从"选择困难"转化为"智能推荐"
- **技术价值**: AI适应人，而非人适应AI
- **情感价值**: "它了解我"的温暖陪伴感

## 2. 核心差异化

### 传统美食App vs PromptX美食专家
- ❌ **传统**: 每次重新询问偏好，无记忆能力
- ✅ **PromptX**: 真正"认识"用户，越用越懂你

### 核心功能架构
```
用户输入 → PromptX角色智能选择 → 记忆学习 → 个性化推荐
```

## 3. 记忆系统设计（核心差异化）

### 个人饮食档案记忆
- 过敏信息：记住并永久避免过敏食材
- 健康目标：减肥/增肌/养胃等长期目标跟踪
- 饮食禁忌：宗教、文化、个人偏好

### 家庭食材库记忆
- 常备食材：鸡蛋、牛奶、面粉等家庭常备
- 临时食材：新买的时令蔬菜、肉类
- 库存管理：提醒过期，建议消耗顺序

### 口味学习进化
- 反馈学习：太淡/太咸的调整记忆
- 偏好识别：重口味/清淡/特定菜系偏好
- 情境适应：工作压力大想吃重口味，身体不适想清淡

### 生活节奏记忆
- 时间规律：工作日快手菜，周末精致菜
- 场景识别：一人食/聚餐/带饭便当
- 季节适应：夏天清爽，冬天温补

## 6. 产品方案详解

### 核心产品逻辑
**用户场景**：回到家不知道做什么菜，有食材但不知道怎么搭配
**解决方案**：告诉AI家里有什么食材，AI基于对用户的记忆推荐适合的菜品，并提供个性化的烹饪指导

### 完整使用流程
```
1. 用户输入：家里有鸡蛋、西红柿、面条
2. AI推荐：西红柿鸡蛋面、鸡蛋面疙瘩、西红柿鸡蛋盖饭(3-5个选项)
3. 用户选择：西红柿鸡蛋面
4. 获得个性化指导：完整烹饪步骤+针对你偏好的调整建议
```

### 推荐内容详解
每个菜品推荐包含：

**1. 基本信息**
- 菜品名称 + 精美配图
- 预估制作时间(15分钟)
- 难度等级(新手/进阶/高手)

**2. 个性化烹饪步骤(核心差异化)**
```
西红柿鸡蛋面制作步骤：

步骤1：处理西红柿
🔸 标准做法：切块炒出汁水
🔹 你的偏好：你喜欢酸甜口，建议多炒一会让汁水更浓郁

步骤3：调味
🔸 标准做法：加1勺糖提鲜
🔹 你的偏好：你喜欢甜口，建议加1.5勺糖，先尝味道再调整

步骤5：煮面条
🔸 标准做法：煮8分钟至软烂
🔹 你的偏好：你喜欢有嚼劲，建议6分钟就捞起
```

**3. 智能营养提醒**
- 在减肥：本道菜约400卡，建议少放油，搭配蔬菜
- 在增肌：蛋白质略低，可以多加一个鸡蛋
- 养胃期：少放辣椒和胡椒，多炖煮一会更好消化

### "懂你"的具体体现
- **记忆口味偏好**：甜/咸/辣/酸的程度，特定菜系喜好
- **记忆饮食禁忌**：过敏食材、宗教禁忌、个人不喜欢的
- **记忆健康目标**：减肥/增肌/养胃等，自动调整推荐
- **记忆制作能力**：新手给简单菜，老手给复杂菜
- **学习反馈**：用户说太淡/太咸，下次自动调整
